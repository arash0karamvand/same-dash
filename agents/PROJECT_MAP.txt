================================================================================
same-Dashboard — نقشه پروژه برای ایجنت‌ها
================================================================================

خلاصه: پنل مدیریت فروشگاه/کارخانه (چند شعبه). بک‌اند Django 6 + MySQL،
فرانت React (Vite). API زیر /api/؛ در توسعه UI روی :5173 و proxy به :8000.

قانون لایه‌ها:
  ui/          → فقط UI و فراخوانی API
  api/views/   → HTTP، اعتبارسنجی ورودی، پاسخ JSON
  logic/       → منطق کسب‌وکار (بدون Request/Response)
  backend/     → مدل‌ها، migration، settings
  auth/        → نقش، مجوز، دکوراتور endpoint

پاسخ API: { "ok": true, "data": ... } یا { "ok": false, "error": "..." }
احراز هویت: session + cookie؛ fetch با credentials: 'include' (ui/src/api/client.js)

--------------------------------------------------------------------------------
۱) ریشه مخزن
--------------------------------------------------------------------------------
manage.py          نقطه ورود Django؛ DJANGO_SETTINGS_MODULE=backend.settings
requirements.txt   وابستگی Python
.env.example       نمونه env (کپی به .env) — DB، SECRET_KEY، DEBUG
.env.xampp         تنظیمات نمونه برای MySQL محلی XAMPP (commit نشود)

--------------------------------------------------------------------------------
۲) backend/ — هسته Django
--------------------------------------------------------------------------------
settings.py        apps، middleware، DB از env، whitenoise
urls.py            /admin/ و include(api.urls) تحت /api/
models.py          تمام مدل ORM (Customer، Sale، AccountingEntry، …)
migrations/        اسکیمای DB — هر تغییر مدل migration جدید
admin.py           پنل ادمین Django
db_backends/       بک‌اند MySQL سازگار (compat_mysql)
management/        دستورات: setup_mysql، reset_business_data، send_birthday_sms، …
soft_delete.py     SoftDeleteModel برای رکوردهای حذف نرم

کار ایجنت: تغییر schema → models + makemigrations؛ تنظیم env در .env نه hard-code

--------------------------------------------------------------------------------
۳) api/ — لایه REST
--------------------------------------------------------------------------------
urls.py            فهرست کامل endpointها (auth، sales، accounting، …)
views/*.py         یک فایل ≈ یک حوزه (sales.py، accounting.py، …)
helpers.py         توابع مشترک view
filters.py         فیلتر/query برای لیست‌ها

نقشه views مهم:
  auth.py              login/logout/me، کاربران، reset داده
  config.py            /api/config/ — منو، شعب، lookup (کش در UI)
  dashboard.py         خلاصه داشبورد
  sales.py             فروش + گزارش + workflow روی sale
  office_orders.py     صف سفارش اداری (جدول جدا)
  factory_orders.py    صف کارخانه / باربری
  customers.py         مشتری + سطح باشگاه
  products.py          محصول و دسته
  materials.py         مواد اولیه و تأیید
  accounting.py        اسناد، دفتر، تراز، import اکسل
  installments.py      اقساط و چک
  attendance.py        حضور و غیاب
  sms*.py              پیامک، تولد، باشگاه، یادآور
  role_definitions.py  نقش‌های پویا، ماتریس مجوز، org-ranks
  org_chart.py         چارت سازمانی

کار ایجنت: endpoint جدید → view + ثبت در urls.py؛ منطق سنگین را در logic/ بگذار

--------------------------------------------------------------------------------
۶) ui/ — فرانت React 19 + Vite
--------------------------------------------------------------------------------
src/App.jsx              رouting داخلی (hash/query)، map صفحه → component
src/pages/*.jsx          هر صفحه یک ماژول (Dashboard، Shop، Accounting، …)
src/components/          Layout، ناوبری، ویجت‌ها، فرم‌های مشترک
src/context/             AuthContext، ConfigContext (منو/شعب از API)
src/api/client.js        تمام URLهای API
src/utils/               permissions.js، routing.js، jalali.js، format.js

پورتال‌ها (منطق محصول): مدیران / فروشگاه / اداری / حسابداری — دسترسی با نقش
vite.config.js           proxy /api → http://127.0.0.1:8000

اجرای dev:
  cd ui && npm run dev
  cd .. && py manage.py runserver 127.0.0.1:8000

کار ایجنت: UI → page + در صورت نیاز متد در client.js؛ مجوز را sync با بک‌اند
